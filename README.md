
# IT Security Checklist

A simple cybersecurity checklist designed to help individuals and small organizations protect their computers, accounts, and networks.

## Account Security
- [ ] Use strong, unique passwords for every account.
- [ ] Enable multifactor authentication (MFA).
- [ ] Review account permissions regularly.

## Device Security
- [ ] Install operating system and software updates.
- [ ] Enable antivirus or endpoint protection.
- [ ] Lock devices when not in use.

## Network Security
- [ ] Change default router passwords.
- [ ] Use WPA2 or WPA3 wireless encryption.
- [ ] Keep router firmware updated.
